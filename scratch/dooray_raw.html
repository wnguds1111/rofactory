1. 서비스 개요

RO Factory는 라그나로크 제로(ROZ) 게임 내에서 사용되는 UGC 에셋인 발자국을 유저가 직접 제작하고, 마켓에서 사고팔 수 있는 크리에이터 플랫폼입니다.

  • 유저 핵심 사이클 : 편집툴 다운로드 → 에셋 제작(.foot/영상/썸네일) → 작품 등록 → 변환 대기 → 변환 진행 → 변환 완료 → 마켓 판매

  • 관리자 핵심 사이클 : 작품 관리(상태별 조회·검색) → 아이템 생성 처리된 엑셀 수급(스튜디오) → 판매 상태 전환 엑셀 업로드(백오피스)

3.2. 마켓 스토어 (Market)

마켓 리스트 : 변환이 완료되어 판매 중(On Sale) 상태인 모든 발자국을 검색하고 구매하는 스토어 페이지

마켓 상세 페이지 : 발자국 상세 정보 페이지 및 구매 전 페이지

구매 완료 페이지 : 구매 완료 후 해당 발자국 로덱스로 지급

4. Admin (백오피스) 서비스

4.1 작품 관리

유저가 등록한 발자국을 관리하는 페이지

판매 업데이트 - 실제 등록된 발자국을 마켓 게시하기 위한 엑셀 업로드

  • 양식 :

    • 마켓ID(생성된 웹 발자국 고유 ID)

    • 아이템ID(스튜디오 발급, 테스트 시 8자 이상 난수 입력),

    • 마켓 게시일

    • 변환 성공 여부

  • 업로드 시 마켓 게시일에 따라 발자국 마켓 게시
