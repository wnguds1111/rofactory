RO Factory CDN 발자국(Footprint) 트래픽 비용 대응 및 유저 크리에이터 콘텐츠(UGC) 활성화를 위해 진행되는 시즌제 콘테스트의 세부 운영 정책서 입니다.

1. 발자국 콘테스트 운영 안 제안

발자국 티켓 지급 및 운영 정책
Operation Proposal
유저가 주도하는 ROZG 정기 'UGC 웹 이벤트 페이지'로의 도약
• 정기 이벤트 페이지로의 정착: 발자국을 직접 등록하고 투표하고 구매할 수 있는 프로세스를 통해, 기존에 접하지 못한 유저 주도형 UGC 정기 이벤트 페이지로 자리 잡기를 제안합니다.
• 기존 웹 이벤트 리소스 재활용 (개발 공수 단축): 라탐(LATAM)에서 이미 구현한 룰렛, 출석체크, 뽑기, 두더지 잡기 등 기존 웹 이벤트 리소스를 적극 활용하여 개발 및 런칭 시간을 대폭 단축하면서도, 유저에게는 매 시즌 다채롭고 풍성한 인터랙티브 경험을 제공합니다. (무료 티켓 지급 + 랜덤 발자국 지급 등 활용 가능)
• 5대 조건 분화 & 혜택 선순환: 기존의 단순 결제 제한 방식을 탈피하여 유효 정액제 / 겟포링 GNJOY 연동 / 기간 내 결제 / 웹 출석을 통해 폭넓은 발자국 등록 권한을 부여하고, 미사용 티켓 환전 및 웹 마켓 구매 혜택을 유기적으로 연동합니다.
• 투표 선정작 소량 출시로 CDN 비용 절감: 인기 투표로 최종 선정된 소량의 발자국만 게임 내에 정식 출시될 예정이므로 CDN 트래픽 및 유지 비용을 대폭 절감하고 퀄리티를 집중 관리할 수 있습니다.
• 자동화를 통한 운영 개입 최소화: 어드민 백오피스에서 단순 일정 세팅 및 마켓 개시 클릭만으로 전 과정이 자동화되어 운영 리소스를 최소화합니다.

단계 설명 비고
01. 일정 세팅 어드민 백오피스에서 유저 발자국 등록 시작/종료일 및 랭킹 선정(투표) 시작/종료일을 회차별 사전 세팅 운영 수동 세팅
02. 접수 개시 이벤트 랜딩 페이지 오픈, 결제 유저 대상 발자국 등록 가능 삭제 시 티켓 미재발급 경고
03. 접수 마감 서버 타임스탬프 기반 신규 등록/수정/삭제 자동 차단, 수집작 Lock 자동
04. 파일 검증 S3 등록 파일 전체 대상 유효성 자동 검증 자동
05. 유저 투표 검수 통과 응모작 전용 투표 사이트 자동 노출(1일 1회 투표) + 미사용 잔여 티켓 웹 환전소 운영 실시간 투표 & 교환 웹
06. 랭킹 선정 유효 득표 순위 상위 10개 당첨작을 100% 유저 투표 결과로 확정 자동
07. 데이터 생성 선정된 발자국 리스트에 아이템 ID 자동 매핑 보안 검증 자동화 확인 필요
08. 마켓 DB 전달 자동 매핑 후 웹 어드민에서 판매 대기 상태 자동 전환 자동
09. 마켓 개시 관리자가 [마켓 상점 일괄 개시] 클릭 시 웹 마켓 + 인게임 상점 동시 활성화 운영 수동 클릭 (2차 확인 모달)
