작품 등록

register.html
페이지 개요
  • 위저드(Wizard) 형태의 4단계 등록 폼 (STEP 0 인트로 포함 총 5화면)
  • GNJOY 로그인 상태에서만 접근 가능, 비로그인 시 로그인 페이지로 리다이렉트
  • 1일 등록 제한: 최대 3회
STEP별 상세
STEP화면명입력 항목벨리데이션
STEP 0 인트로 안내 없음 (안내 전용) 없음
STEP 1 파일 준비 안내 없음 (UGC 편집툴 다운로드 안내) 없음
STEP 2 파일 업로드 + 약관 ① 발자국 원본 .foot 필수
② 동영상 미리보기 .mp4/.mov 필수
③ 콜렉션 썸네일 .png 필수
④ 아이템 썸네일 .png/.jpg 필수
⑤ 약관 동의 체크 필수 		• 약관 미동의 시 다음 단계 진행 불가
• 약관은 스크롤 끝까지 내려야 동의 활성화
• alert('약관에 반드시 동의해야 다음 단계로 진행할 수 있습니다.')
STEP 3 마켓 정보 입력 ① 작품 카테고리: 발자국 (고정)
② 판매 금액 필수 (0 = 무료배포, 숫자만 입력) KP 단위
③ 게시만료일 필수 (MM.DD.YYYY 텍스트 입력)
④ 작품명 필수 (영문만 입력 가능, 최대 20자)
⑤ 작품 타입 태그 선택 (최대 2개 다중선택)
⑥ 메인 색상 선택 (select 드롭다운) 		• 작품명 미입력 시
alert('작품명을 입력해주세요. (영문만 입력 가능)')
• 게시만료일 미입력 시
alert('작품 게시기간 만료일을 필수로 입력해주세요. (MM.DD.YYYY)')
• 게시만료일 형식 오류 시
alert('게시 만료일 형식이 올바르지 않습니다. MM.DD.YYYY 형태로 입력해주세요.')
• 게시만료일은 현재일 기준 최소 30일 이상
• 타입 태그 3개 선택 시 가장 오래된 선택 자동 해제 (큐 로직)
STEP 4 등록 완료 없음 (완료 안내) • 잔여 등록 횟수 표시 (일 3회 제한)
• MY STUDIO 이동 버튼 제공
약관 모달 동작
  • 약관 내용을 스크롤 끝까지 내려야 동의 버튼 활성화
  • 활성화 전 버튼 텍스트: "스크롤을 끝까지 내려주세요" / 활성화 후: "확인 및 약관 동의하기"
  • 체크박스는 disabled 상태 → 모달 동의 후 자동 체크
