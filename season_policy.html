RO FACTORY 시즌 콘테스트 운영 정책서

발자국 콘테스트의 시즌 일정, 작품 처리 프로세스, 작품 상태, 티켓·선정·보상, 제작자 정보 노출, 위반 작품 처리 기준을 정리한 문서입니다. GGU 회신(08.24, 09.17)과 웹팀 작품 처리 프로세스를 기준으로 작성했습니다.

핵심 요약

  • 투표 상위 30개 작품을 게임에 출시하며, 계정당 당첨 수 제한은 없습니다.
  • 정액제 이용 유저에게 사이클당 티켓 30장을 지급합니다. 남은 티켓은 사이클 종료 시 소멸하며, 환전·교환은 없습니다.
  • 선정되지 않은 참여자 중 100명을 추첨해 이벤트 포션을 RODEX로 지급합니다.
  • 제작자는 마스킹한 계정 이메일(예: to*****99@gmail.com)로 표기합니다.
  • 당첨작은 게임 리소스가 반영된 뒤 어드민이 구매를 열어야 구매할 수 있습니다.
  • 위반 작품은 마켓에서 삭제하고, 이미 지급된 아이템은 회수하지 않고 이펙트만 제거합니다.

한 시즌은 작품 등록 기간 → 투표 기간 → 투표 종료 페이지 순서로 진행되고, 다음 시즌 시작일에 다시 작품 등록 기간으로 돌아갑니다.

작품 상태 정의

작품은 아래 7가지 상태 중 하나를 가집니다.

변환 중 유효성 통과→ 투표 중 1~30위→ 판매 대기 어드민 구매 오픈→ 판매 중 90일 경과→ 작품 만료
분기
변환 중 유효성 실패→ 변환 실패
투표 중 31위 이하→ 마켓 삭제
판매 대기 판매 중 관리자 수동 삭제→ 마켓 삭제
상태 정의 진입 시점 투표·마켓 노출 구매
변환 중 업로드했고 유효성 검사 결과가 아직 나오지 않은 작품 업로드 즉시 비노출 불가
변환 실패 유효성 검사를 통과하지 못한 작품 등록 기간 종료 후 검사 시 비노출 불가
투표 중 유효성을 통과해 투표 리스트에 오른 작품 투표 기간 시작일 투표 리스트 불가
판매 대기 1~30위로 확정됐고 아직 구매가 열리지 않은 작품 (아이템 ID 부여, 게임 리소스 반영 대기) 투표 기간 종료일 투표 종료 페이지 불가
판매 중 어드민이 구매를 연 당첨작 어드민 구매 오픈 시 투표 종료 페이지, 마켓 가능
작품 만료 판매 중 상태로 90일이 지난 작품 90일 경과 시 비노출 불가
마켓 삭제 31위 이하로 선정되지 않은 작품, 또는 관리자가 수동으로 삭제한 작품 투표 기간 종료일 / 관리자 삭제 시 비노출 불가
판매 중 전환 시점: 상태 정의 초안은 "아이템 ID 부여 완료 = 판매 중"이었지만, 프로세스상 구매는 어드민 구매 오픈 후에만 가능합니다. 이 문서는 어드민 구매 오픈 시점을 판매 중 진입 기준으로 정의했습니다. (8장 1번)

사이클 중 정액제 종료 이미 지급된 티켓은 유지. 정액제를 다시 구매하면 같은 수량을 그대로 이용 가능 확정GGU 08.24 ③-1안
환전·교환 없음. 남은 티켓은 아이템이나 재화로 바꿀 수 없고 만료됨 확정GGU 09.17 #5
