🔄 시스템 플로우차트 (Flow Map)

RO FACTORY 클라이언트 ↔ 웹 ↔ 어드민 시스템 서비스 전체 플로우

1 클라이언트 ↔ 웹 ↔ 어드민 연동 데이터 플로우
발자국 에셋이 제작되어 마켓에 판매되기까지의 전체 상세 프로세스입니다.
1
🖥️ 클라이언트 (편집툴)
발자국 에셋 제작 및 파일 추출
발자국 에셋 원본 파일(.foot) 및 영상 미리보기 파일, 파일 식별을 위한 META 파일은 전용 UGC 편집툴(데스크톱)을 통해 제작합니다.
📄 .foot (원본 에셋) 🎬 .mp4 (미리보기 영상) 🖼️ .png (썸네일) 📋 meta (파일 식별 정보)
▼
.foot + .mp4 + .png + meta 전달
2
🌐 웹 포털 (프론트)
웹 포털 등록 폼에서 업로드 → S3 적재
편집툴에서 추출한 리소스를 웹 포털 등록 폼에서 업로드합니다.
업로드된 파일은 S3 스토리지에 적재되며, 작품명·태그·유효기간 등 메타데이터도 함께 저장됩니다.
* PC 전용 · 로그인 필수 · 주간 100개 제한
▼
S3 스토리지 적재 완료
3
🔧 스튜디오 (서버)
S3 접근 → 등록 데이터 수집 → 아이템 ID 부여
S3에 접근하여 유저가 등록한 발자국 등록 데이터를 수집한 뒤, 각 작품에 고유 아이템 ID를 부여합니다.
🔑 아이템 ID 발급 📦 .foot 무결성 검증
▼
아이템 ID + 검수 결과 전달
4
⚙️ 어드민 (백오피스)
백오피스 접근 → 게시할 발자국 업로드
백오피스에 접근하여 검수가 완료된 발자국을 게시용으로 업로드합니다.
엑셀(CSV) 일괄 업데이트를 통해 판매 시작일, 아이템 ID 등을 반영합니다.
📊 CSV 일괄 업데이트 📅 판매 시작일 설정
▼
판매 시작일 도달 시 자동 노출
5
🛒 마켓 (웹 스토어)
마켓 판매 시작
마켓 스토어에 발자국이 노출되어 판매가 시작됩니다.
현재 FREE 버전으로 운영 중이며, 추후 유료화(KP 결제) 진행 예정입니다.
🟢 현재: FREE 📌 추후: KP 유료화 예정
2 유저 작품관리 상태 값 (마이 스튜디오 > My Works 기준)
유저는 본인 스튜디오에서 작품이 검수되고 마켓에 오르기까지 4가지 상태를 확인하게 됩니다.
  • 변환 중 작품을 최초 업로드한 뒤 관리자의 에셋 다운로드 및 오류 검수 처리를 기다리는 등록 대기 상태입니다. (수정 불가)
  • 판매 대기 관리자 검수가 무사 통과되어 승인되었으나, 설정된 판매 시작일이 아직 도달하지 않아 마켓 노출이 대기 중인 상태입니다. (수정 불가)
  • 변환 실패 클라이언트 에셋 검증 중 파일 결함(.foot 오류 등), 또는 정책 위반 사유로 관리자(어드민) 단에서 등록 반려를 내린 상태입니다. (해결 후 별도로 재등록 필요)
  • 작품 만료 정상적으로 마켓에 올라 판매되다 판매 기간(유효기간, 예: 1년)이 종료되어 마켓 노출과 거래가 영구 중지된 과거의 작품 기록입니다.
3 어드민 작품관리 상태 값 (관리자 백오피스 작품 관리 기준)
운영진(관리자)은 유저가 올린 방대한 데이터를 통제하고 다루기 위해 보다 세분화된 5가지 상태 값(필터링 탭)을 기준으로 관리합니다.
  • 변환 대기 프론트 웹에서 방금 넘어온 따끈한 신규 데이터입니다. 관리자가 묶음 에셋 파일(.foot)을 로컬로 내려받아 툴 검증을 착수해야 하는 '가장 우선 타겟' 업무 리스트입니다.
  • 변환 완료 어드민에서 정상(엑셀 업데이트 성공) 판정 후 마켓 대기 상태로 걸쳐있는 작품입니다. 등록한 '판매 시작일'이 도래할 때까지 대기하는 상태입니다.
  • 판매 진행 작품 검수 통과 후 판매 시작일자가 지나 현재 실시간으로 웹 스토어 상에서 대중에게 노출 및 KP 기반 거래가 일어나고 있는 핵심 라이브 작품입니다.
  • 변환 실패 엑셀 단체 업데이트 처리를 통해 결함 검출로 인한 실패(N) 상태를 확정한 작품입니다. 영구 노출 차단입니다.
  • 작품 만료 정상 서비스 기간이 경과하여 라이브 마켓에서 삭제되었고, 히스토리 조회 목적으로만 남겨두는 과거의 데이터 저장고 탭입니다.
